# MCIT-# MCIT Sovereign 100% Local Multi-Agent AI & RAG Platform
### منصة الوكلاء الأذكياء المتعددين لوزارة الاتصالات وتكنولوجيا المعلومات (سيادية ومحلية 100%)

---

## Overview | نظرة عامة

**English:**
The **MCIT Sovereign 100% Local Multi-Agent AI & RAG Platform** is an enterprise-grade, privacy-first artificial intelligence solution custom-built for the Ministry of Communications and Information Technology (MCIT). Designed to operate entirely on-premise without reliance on external cloud services or third-party APIs, it ensures complete data sovereignty, zero data leakage, and full compliance with national security guidelines.

**العرية:**
**منصة الوكلاء الأذكياء المتعددين لوزارة الاتصالات وتكنولوجيا المعلومات (MCIT Sovereign 100% Local Multi-Agent AI & RAG Platform)** هي حل ذكاء اصطناعي سيادي ومحلي بالكامل مصمم خصيصاً لوزارة الاتصالات وتكنولوجيا المعلومات. تعمل المنصة بالكامل داخل البنية التحية المحلية (On-Premise) دون أي اعتماد على لسحابة الخارجية أو واجهات برمجية خارجية، مما يضمن اسيادة التامة على البيانات، ومنع تسريب العلومات، والالتزا بأعلى معايير الأمان السيبراني.

## User Panel & The 4 AI Agents | لوحة المتخدم والوكلاء الأربعة

### 1. User Panel | لوحة المستخدم
* **English:** Intuitive, responsive web dashboard allowing government employees to interact seamlessly with multiple specialized AI agents, manage document uploads, query internal databases, and export generated deliverables.
* * **الربية:** واجهة مستخدم تفاعلية وسلسة تمكّن موظفي الوزارة من التفاعل المباشر مع مختلف الوكلاء الأكياء، تحميل المستندات والوثائق، استلام قواعد المعرفة الدخلية، وتصدير المخرجات.
 
  * ### 2. Specialized AI Agents | الوكلاء الربعة الأذكاء
 
  * #### 1. Summarization Agent | وكيل التلخيص الذكي
  * * **English:** Summarizes lengthy policy documents, technical reports, legal decrees, and ministerial briefs into actionable executive summaries, key bullet points, and decision matrices.
    * * **العربية:** يقوم بتلخيص التقارير الفنية، السياسات الحكومية، المذكرات الوزارية، والقرارات القانونية إلى ملخصات تنفيدية دقيقة ومحددة تسهم في تسريع اتخاذ القرار.
     
      * #### 2. Presentation Agent | وكيل العروض التقديمية
      * * **English:** Transforms raw research, reports, and data into structured presentation slide outlines, slide-by-slide narratives, visual layouts, and formatted slide content ready for official briefings.
        * * **العربية:** تحويل النصص والتقارير والدراست لى هياكل عروض تقديمية (Presentation Slides) متكاملة مصممة وفق الهوية المؤسسية للوزارة جاهة للعرض المباشر.
         
          * #### 3. Infographic Agent | وكيل الإنفوجرافيك البصري
          * * **English:** Extracts numerical statistics, KPIs, process workflows, and structural hierarchies from raw data to generate visual infographic specs, tables, and structured data visualizations.
            * * **العربية:** استخراج الإحصائيات والأرقام الرئيسية ومؤشرات الداء (KPIs) سلاسل العمليات وتنسيقها في مخططات إفوجرافيك بصرية جذابة وسهلة الفهم.
             
              * #### 4. Local RAG System | نظام الأسئلة والأجوبة الاسترجاعي
              * * **English:** Local Retrieval-Augmented Generation system enabling high-precision semantic search and natural language Q&A over internal Ministry documents, archives, and knowledge bases using local vector embeddings.
                * * **العربية:** نظام استرجاع امعرفة المعزز باتوليد المحترس المحلي (Local RAG) للبحث الدقيق والإابة عن الاتفسارات بناءً على المستندات والوثائق الداخلية للوزارة باستخدام متجهات البحث الحلية.

                  * ## Admin Panel & Usage Dashboard | لوحة تحكم المسؤول وإدارة المستخدمين
                 
                  * ### 1. Admin Panel & Usage Analytics | لوة تحكم المسؤول والإحصائيات
                  * * **English:** Comprehensive administrative controls for monitoring system resource utilization (GPU/CPU/RAM), active model latency, prompt token counts, agent usage trends, and system audit logs.
                    * * **العربية:** لوحة تحكم شاملة لمسؤولي النظام لمراقبة استهلك الموارد (GPU/CPU/RAM)، سرعة واستجابة انماذ، عدد الرمزات (Tokens)، وتحليلات استخدام الوكلاء مع سجلات تدقيق لأمان (Audit Logs).
                     
                      * ### 2. User & Permission Management | إدارة المستخدمين والصلاحيات (Add/Suspend/Delete Users)
                      * * **English:** Granular Access Control (RBAC) allowing administrators to:
                        *   * **Add Users (إضافة مستخدمين):** Provision new accounts with assigned roles (Admin, Analyst, Standard User).
                            *   * **Suspend Users (تعليق حسابات):** Temporarily block access or restrict user capabilities during security audits.
                                *   * **Delete Users (حذف المستخدمين):** Remove user access and retain clean audit trails.
                                    * * **العربة:** إدارة دقيقة وصارمة لصلاحيات الوصول تنطوي عل:
                                      *   * **إضافة مستخدمين جد (Add Users):** إنشاء حسابات مع تحديد الدور والصلاحيات (مسؤول، محلل، ستخدم عادي).
                                          *   * **تعليق الحسابات (Suspend Users):** حظر مؤقت للحسابات عند لحاجة أو إجراء الفحوصات الأمنية.
                                              *   * **حذف المستخدمين (Delete Users):** إزالة الحسابات وإدارة سجلات الوصول بفعالية.

                                                  * ## Project Directory Structure | هيكل ملفات المشروع
                                               
                                                  * * `mcit_multi_agent_platform.html`: Frontend Web Interface (User Panel & Admin Dashboard).
                                                    * * `agents_orchestrator.py`: Multi-Agent Router, Prompt Engineering & Orchestration Logic.
                                                      * * `backend_app.py`: FastAPI Backend REST API & Ollama Connector.

                                                            * ---
                                                           
                                                            * ## Local Deployment Steps | خطوات التشغيل المحلي (Ollama & FastAPI)
                                                           
                                                            * ### Prerequisites | المتطلبات الأساسية
                                                            * * Python 3.10+
                                                              * * Ollama (Local LLM Runtime)
                                                                * * Docker & Docker Compose (Optional)
                                                                 
                                                                  * ### Step 1: Install & Run Ollama | تشغيل نموذج Ollama المحلي
                                                                  * ```bash
                                                                    ollama pull llama3
                                                                    ollama run llama3
                                                                    ```

                                                                    ### Step 2: Setup Python Backend | إعداد الخلفية ابرمجية
                                                                    ```bash
                                                                    git clone MCIT-Multi-Agent
                                                                    cd MCIT-Multi-Agent
                                                                    python -m venv venv
                                                                    source venv/bin/activate
                                                                    pip install fastapi uvicorn langchain ollama pydantic sqlalchemy
                                                                    ```

                                                                    ### Step 3: Initialize Database | تهيئة قادة البيانات
                                                                    ```bash
                                                                    sqlite3 mcit_platform.db < database_schema.sql
                                                                    ```

                                                                    ### Step 4: Run FastAPI Application | تشغل خادم FastAPI
                                                                    ```bash
                                                                    uvicorn backend_app:app --host 0.0.0.0 --port 8000 --reload
                                                                    ```

                                                                    ### Step 5: Docker Deployment (Alternative) | التشغيل عبر Docker Compose
                                                                    ```bash
                                                                    docker-compose up -d --build
                                                                    ```
